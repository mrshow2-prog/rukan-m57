# M57 Rukan Townhouse Tour

A self-contained virtual tour of the M57 Rukan townhouse in Dubai.

- 3D cutaway layout of each floor as the menu: tap a room to fly in and see its photos
- 360° look-around views for the bedroom and master bedroom
- 2D floor plans for both floors
- Guided walkthrough from the front yard through both floors
- WhatsApp button to schedule a viewing

## Run it

Open `index.html` through any static web server (for example `python3 -m http.server`),
or publish the repository with GitHub Pages. The 360° viewer loads three.js from cdnjs.

## Files

- `index.html` – the whole tour (HTML, CSS and JavaScript in one file)
- `img/` – layouts, floor plans, room photos and 360° panoramas
